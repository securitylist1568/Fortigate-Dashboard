Quota-Safe SOP
治理面向 受控端點 / 檔案 現行保護設定規格 (v2.5.0) 後續滾動式改版必須遵守之鐵則（Do's & Don'ts）
1. 主快照 API 邊緣快取 src/app/api/snapshot/route.ts Cache-Control: public, max-age=60, s-maxage=180, stale-while-revalidate=600
＋ 伺服器記憶體 cachedEncryptedSnapshot 		嚴禁改回 private, no-store 或加回 dynamic = 'force-dynamic'。因為回傳內容已是 AES-256-GCM 密文，必須維持 Edge CDN 快取以將流量導向 100GB 的 Fast Data Transfer。
2. 前端初次載入請求控制 src/app/page.tsx hasInitializedRef 鎖定單次執行 ＋ 乾淨 URL fetch('/api/snapshot') 嚴禁在 fetch('/api/snapshot') 附加 ?t=Date.now() 破快取參數；嚴禁將經常變動的 React State 放入初始化 useEffect 的依賴陣列中。
3. IP 查詢端點與歷史索引 src/app/api/query-ip/route.ts
src/lib/cti-fetcher.ts 		前端使用 GET /api/query-ip?q=...（s-maxage=300）＋ ipQueryCacheRef 前端記憶；後端 10 日歷史索引採按需載入（2 小時快取） 保持「先查現行 HEAD 25 份清單，未命中封鎖時才載入 10 日歷史索引」的兩階段設計，避免冷啟動時無條件拉取 100 個歷史檔案。
4. 靜態資源與圖示快取 src/app/icon.svg
next.config.mjs 		/(robots\.txt|favicon\.ico|icon\.svg) 強制設定 s-maxage=604800, immutable 不可刪除 src/app/icon.svg，避免瀏覽器自動請求圖示時觸發 404 Not Found 動態回源。
5. 跨儲存庫清單同步規範 src/lib/feeds.manifest.ts
README.md 		26 份清單之 file 與 displayName 100% 對齊 Fortigate 儲存庫 當 Fortigate 新增、刪除或更名任何 *.txt 清單時，必須同步更新 feeds.manifest.ts 與雙庫 README.md。
